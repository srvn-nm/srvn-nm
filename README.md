## 🔬 Research: teaching LLMs to find vulnerabilities

My undergraduate thesis fine-tuned **WizardCoder-13B** (LoRA/PEFT, 8-bit, focal loss, batch packing) to detect vulnerabilities in Java — trained on real-world CVE data + OWASP Benchmark, evaluated honestly on held-out imbalanced data.

**Result: 0.91 recall (F1 0.66)** in the high-sensitivity configuration — and a precision/recall trade-off analysis showing *which* detector belongs *where* in a security pipeline.

→ **[Software-Vulnerability-Detection](https://github.com/srvn-nm/Software-Vulnerability-Detection)** — code, method, results table
